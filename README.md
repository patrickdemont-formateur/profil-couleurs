# Profil de management par les couleurs v2.2

## Évolution principale
- Le contrôle `range` a été entièrement supprimé.
- Chaque question propose six pastilles cliquables sans valeur visible.
- Aucune barre de progression colorée n’existe dans l’échelle de réponse.
- La pastille sélectionnée devient bleue et reste clairement visible.
- Les valeurs 1 à 6 restent uniquement internes au calcul.

## Mise à jour GitHub Pages
Remplacez tous les fichiers du dépôt par le contenu de ce dossier, sans changer la configuration GitHub Pages. Les paramètres `?v=2.2` ajoutés aux fichiers CSS et JavaScript limitent les problèmes de cache.

## Test
Rechargez la page avec `Ctrl + F5` après publication. Le stockage local utilise une nouvelle clé v2.2, donc les anciennes réponses ne sont pas reprises.

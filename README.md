# Profil de management par les couleurs v2.3

## Évolutions
- Six boutons en forme de capsules reliés visuellement par un rail gris.
- Légendes symétriques : forte, moyenne, légère pour A puis légère, moyenne, forte pour B.
- Point neutre central visible et non sélectionnable pour matérialiser la bascule entre A et B.
- Aucune valeur numérique affichée dans le questionnaire.
- Échelle du radar dynamique : le maximum est recalculé à partir du score le plus élevé et arrondi au multiple de 5 supérieur afin de rendre l’aire plus lisible.
- Nouvelle clé de stockage local v2.3 et paramètres de cache `?v=2.3`.

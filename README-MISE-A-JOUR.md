# Mise à jour 2.1

Cette archive contient uniquement les trois fichiers modifiés : `index.html`, `css/style.css` et `js/app.js`.

Le fichier `data/questions.json` de votre dépôt reste inchangé.

## Installation

1. Faites une sauvegarde ou créez une branche.
2. Remplacez les trois fichiers correspondants dans le dépôt.
3. Validez les changements sur la branche publiée par GitHub Pages.
4. Rechargez la page en forçant l’actualisation si nécessaire.

## Changements

- curseur centré, sans numérotation visible ;
- état central initial non comptabilisé ;
- préférences gauche et droite indiquées textuellement ;
- intensité légère, marquée ou forte ;
- radar à échelle dynamique ;
- nouveau message méthodologique dans la page et le PDF.
